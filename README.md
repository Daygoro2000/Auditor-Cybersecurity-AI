# Asistente de Ciberseguridad y Compliance — MIDTECH S.A.
### TFC #include13 · Fundación GoodJob · 2026

Asistente conversacional de ciberseguridad y compliance construido con n8n, Groq, Ollama y Supabase para analizar la política de seguridad de MIDTECH S.A. frente a GDPR, ISO 27001 y ENS.

---

## Contenido del repositorio

**`informe/`** — Informe técnico completo del proyecto en PDF con todas las fases documentadas, capturas de evidencia y anexo de prompts.

**`workflows/`** — Exportación en JSON de los dos workflows de n8n: el de indexación de documentos y el del asistente IA.

**`database/`** — Esquema SQL de la base de datos Supabase y la función RPC `base_conocimiento()` utilizada para la búsqueda semántica.

**`prompts/`** — Prompt de sistema del AI Agent en formato TXT.

**`videos/`** — Enlaces a las grabaciones de demostración de las cuatro capacidades del asistente, alojadas en Google Drive.
